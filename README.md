# Ariel Okal Poster

This project is a React recreation of the **Ariel Okal** poster from the provided Figma design.

## Poster Chosen

- Ariel Okal Poster

## Running the Project

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
